# Number-AI: a PyTorch learning project

**Number-AI** is a (creatively named) **PyTorch** project which devs _Milkychicken_ and (not as actively) _Venicro_ have created to solidify their PyTorch skills. \
Once finished, the program *should* be able to recognize and identify individual digits* shown to your device's camera (heavy emphasis on the should).

*_(maybe numbers too? In the far, far future...)_
## Installation guide
In your projects directory:

    git clone git@github.com:Milkychicken/Number-AI.git
alternatively, without ssh: 

    git clone https://github.com/Milkychicken/Number-AI.git

further installation (package installation):

    cd Number-AI
    uv init .
    uv add torch scikit-learn
